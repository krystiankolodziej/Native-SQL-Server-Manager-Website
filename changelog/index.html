Changelog

Every release, and what actually changed in it. Updates are included in the purchase price.

1.2.0

Azure SQL redirects

The client now follows server redirects, so databases behind the Azure SQL Redirect connection policy connect and run queries instead of failing after sign-in. The connection time limit went up to 30 seconds, the value Azure itself puts in its connection strings, which leaves room for the two-step sign-in a redirect requires.

Query tabs stored on disk

Open tabs and their scripts used to live in the app preferences, where a few large scripts could slow the whole app down and make new connections time out. Each tab is now kept as its own file in the app’s data folder, saved one at a time, so a tab with a long script costs nothing on the others. Existing tabs migrate automatically on first launch.

Entra ID sign-in that stays signed in

Opening another tab or reconnecting after a dropped connection reuses the token from the first sign-in instead of asking again. On macOS the token cache lives in a different keychain group than on iOS, which is why silent sign-in never found it before.

Fixes

  • Hovering a tab shows its title, server and database.
  • Result columns are sized to their values as well as their names, so dates and identifiers show in full.
  • Running a tab on a different server than it was opened on now clears the previous database instead of asking the new server for it.
  • Entra ID tabs no longer ask, after every restart, whether to reconnect to the same server.
  • Nothing starts, and nothing lands in the history, until the question about where to run a query is answered.
  • Choosing a default data formatter in Preferences shows the selection, and a formatter can be removed with the Delete key or the context menu.
  • The connection window no longer grows after picking an entry from the history.

1.1.0

Graphical execution plans

The headline addition. Switch on Include Actual Execution Plan and the plan comes back as a diagram rather than XML, laid out the way SQL Server Management Studio lays it out: operators left to right, relative cost shown per operator, and warnings marked on the nodes that carry them. The plan and the results split the window, and the whole tree can be walked from the keyboard. Statements that return no operator tree keep their normal results grid.

Faster object tree on very large databases

Expanding a database with sixteen thousand tables no longer crawls. Row counts, schema resolution and lazily loaded nodes were rebuilt to avoid the quadratic work that made large catalogues painful.

Fixes

  • Grid editing and cell formatting now follow the value’s real type rather than a guess.
  • Disconnect releases the connection immediately instead of waiting on a dead request stream.
  • Loading a database no longer expands unrelated subtrees on other connections.
  • A binary parameter no longer prevents the result columns from being described.
  • Running a selection containing emoji executes the whole selection.
  • Several crashes and rendering faults in the results grid.

1.0

First release. A native SQL Server client for macOS that speaks TDS directly — no ODBC driver, no Homebrew, no Java or Electron runtime.

  • SQL authentication, Microsoft Entra ID (browser, device code, username and password, or a service principal), Kerberos single sign-on and NTLM.
  • Several servers at once, each tab holding its own session, with queries that can be cancelled.
  • A T-SQL editor driven by the real schema: autocompletion, parameter hints, themes, a formatter and searchable history.
  • An objects explorer covering every database on the server, down to keys, constraints, indexes, dependent views and routine parameters.
  • Scripting to CREATE and DROP for any object, SELECT, INSERT, UPDATE and DELETE for tables, and CREATE, ALTER or CREATE OR ALTER for routines, with a parameters form for executing them.
  • In-grid editing, copying rows as SQL statements, export to CSV, JSON, XML and SQL, and CSV import.
  • Table, view, index and column properties, including an editor for extended properties.
