# Assets

Pliki do dostarczenia:

- `og-image.png` — obrazek podglądu przy udostępnianiu linku (Open Graph / Twitter), zalecane 1200×630 px.

Dostarczone:

- `MainWindow.png` — zrzut głównego okna aplikacji (2142×1382, przezroczyste tło z cieniem okna macOS); pokazywany pod hero.
- `icon.png` — ikona aplikacji (render z Icon Composer), 512×512 px; używana w headerze, jako favicon i apple-touch-icon.
- `fonts/zilla-slab-500.woff2`, `fonts/zilla-slab-600.woff2` — Zilla Slab (Google Fonts, licencja OFL), self-hostowane; używane w nagłówkach jako odpowiednik MuseoSlab z shottr.cc.
